4. Modular Boundary — CRITICAL
------------------------------
Seed logic must respect module ownership.

Users:
- seed account through UserAccountService

AccessControl:
- seed roles/permissions/assignments through AccessControlService

Auth:
- do NOT seed auth_sessions
- sessions must be created through normal login

Do NOT:
- insert rows directly through foreign module repositories
- import UserEntity into AccessControl seed logic
- manipulate auth_sessions manually
- bypass normalization/validation services without strong reason
