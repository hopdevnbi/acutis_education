-------------------------------------

AccessControlModule must NOT query UserEntity directly.

Evaluate two options:

A. Rely on SQL FK and map FK violation
B. Ask UsersModule public contract to validate user existence

For modular extraction readiness:

Preferred:

But avoid adding a dependency unless useful.

Document decision.

This is still acyclic:

Evaluate carefully.

24. PermissionGuard
-------------------
Implement PermissionGuard.

Dependencies:
- Reflector
- AccessControlService

Expected flow:

1. retrieve required permissions metadata
2. read authenticated user context from request
3. if route has no required permissions:
   decide behavior
4. resolve/check user permissions
5. allow or throw ForbiddenException

25. Guard Composition
---------------------
PermissionGuard assumes JwtAuthGuard has already authenticated request.

Preferred route usage:

@UseGuards(JwtAuthGuard, PermissionGuard)
@RequirePermissions('users.read')

Do not make PermissionGuard re-verify JWT.

Clear separation:
- JwtAuthGuard = authentication
- PermissionGuard = authorization
