BOUNDED CONTEXT
---------------
Audit module naming and boundaries.

DOMAIN DEFINITIONS
------------------
Define precisely:

Question:
long-lived stable semantic identity.

QuestionVersion:
point-in-time authoring/publishing snapshot.

QuestionType:
stable language-neutral machine code controlling render + answer semantics.

QuestionOption:
version-scoped selectable item.

CorrectAnswer:
machine-evaluable answer definition independent of localized display text.

Explanation:
feedback text owned by a question version.

QuestionTag:
search/classification metadata.

Question Curriculum Link:
classification/linkage to Curriculum/Lesson without transferring ownership.

VERSION MODEL
-------------
Audit and strongly consider:

questions
= stable root identity

question_versions
= versioned content/answers

Lifecycle:
DRAFT
PUBLISHED
ARCHIVED

Rules:
- one DRAFT per question
- published immutable
- edits after publish require clone → new DRAFT
- versionNumber monotonic
- publishing newer version archives previous current published version
- historical published/archived versions remain readable for audit

Future Exam must reference EXACT questionVersionId, never mutable question root state.

An exam attempt must remain gradable even if author publishes a newer question version later.

SINGLE_CHOICE
-------------
- 2..N options
- exactly one correct
- correctness references option ID, not display text
- explicit canonical sort order

MULTIPLE_CHOICE
---------------
- 2..N options
- >=1 correct
- default exact-set scoring
- no partial credit until product explicitly defines it

TRUE_FALSE
----------
Audit whether to model as:
A. two ordinary options
B. boolean answer definition

Choose the model that keeps learner rendering and grading simplest without encoding correctness in display labels.

SHORT_TEXT / NUMBER
-------------------
If deferred, explain why.

If planned:
SHORT_TEXT raises locale/case/accent/alias complexity.
NUMBER requires numeric value/tolerance independent of formatted display strings.

Do not invent fuzzy grading policy now.

OPTION IDENTITY
---------------
Options need version-scoped UUID IDs.

Correct answer must reference IDs, never:
- array index
- label text
- translated string

Canonical order stored by sortOrder.
Practice/Exam may shuffle delivery later.

If shuffled, Exam stores delivered order.

Do not randomize at persistence layer.
