5. Define Domain Terms Precisely
--------------------------------
Propose exact definitions:

Curriculum
= a structured curriculum definition/program for a parish/level or reusable catalog.

Topic
= ordered unit/chapter/theme within a curriculum.

Lesson
= teachable unit within a topic.

Learning Content
= the actual instructional content attached to a lesson:
text blocks, sections, references, media references, activities, etc.

Do not treat all four as synonyms.
