AUTOMATIC BADGE PROCESSOR
-------------------------
Extend reward ingest with internal BadgeAwardProcessor.

For each event:
1. find ACTIVE AUTOMATIC/BOTH badge definitions
2. scope-match GLOBAL/PARISH
3. type-match rule
4. evaluate against event or Gamification-owned event history
5. award at most once per student
6. duplicate/replay = no-op
7. award optional pointsBonus
8. keep Gamification-side effects atomic where practical

Do NOT query source-domain repositories for counts.

BADGE POINTS BONUS
------------------
On award with pointsBonus > 0 append ledger:
sourceType = BADGE_BONUS
sourceId = badgeAward.id
reasonCode = stable badge code/prefixed code
pointsDelta = pointsBonus
server-derived student/enrollment/parish context
awardedByUserId null for automatic, actor for manual if appropriate

Prevent duplicate bonus.

On revoke:
do not mutate/delete old bonus row.
Create one compensating REVERSAL if bonus exists.
Prevent repeated reversal.
