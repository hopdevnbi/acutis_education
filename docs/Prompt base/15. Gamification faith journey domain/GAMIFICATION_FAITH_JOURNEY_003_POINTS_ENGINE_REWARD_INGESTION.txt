PART C — TRANSACTION / IDEMPOTENCY ORDER
==================================================

This is critical.

Do NOT mark event as processed before ledger writes can safely complete outside the same transaction.

- detect/insert event receipt
- evaluate rules
- append ledger
- commit all together

If duplicate ledger identity for one rule:
