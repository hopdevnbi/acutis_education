21. Link Guardian
-----------------
POST /api/v1/students/:studentId/guardians

Input:
- guardianUserId
- relationshipType
- isPrimary optional/default false

Flow:
1. student exists and ACTIVE
2. guardianUserId valid/existing User
3. reject guardian user linked to same student as currently ACTIVE
4. if isPrimary=true:
   ensure no existing ACTIVE primary guardian
5. create new ACTIVE row
6. return snapshot

DB filtered indexes already enforce race safety.

Map conflicts cleanly.

22. Historical Re-link
----------------------

Do NOT reactivate old historical row.

History remains append-style.
