5. Critical Identity Question
-----------------------------

A. separate identities/accounts
B. profile tables linked to User

31. Enrollment Uniqueness
-------------------------
Critical.

Should a student have only one ACTIVE enrollment per academic year?

Likely yes within same parish.

But transfer requires:
old -> TRANSFERRED/WITHDRAWN
new -> ACTIVE

Potential DB invariant:
only one ACTIVE enrollment for a student per academic year.

Since enrollment row references class, academic year derived from Class.

DB filtered unique index cannot easily include academic_year without duplication unless denormalized.

Audit options:
- duplicate academic_year_id into enrollment for invariant
- service transaction/lock
- query via join

Do not choose casually.
