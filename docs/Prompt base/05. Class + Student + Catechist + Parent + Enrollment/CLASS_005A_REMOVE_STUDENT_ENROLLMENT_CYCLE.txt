5. Required Ownership Fix
-------------------------
The parish student list depends on enrollment-owned data:

- active enrollment rows
- parishId
- academicYearId
- student IDs

Therefore orchestration belongs on the Enrollment side.

Preferred design:

EnrollmentModule:
- owns EnrollmentQueryService
- imports StudentModule
- has a thin controller/orchestrator for:
  GET /api/v1/parishes/:parishId/students

The controller/service:
1. queries EnrollmentQueryService for distinct student IDs matching parish filters
2. calls StudentService public API for safe StudentSnapshots
3. returns the same FE-safe response contract

StudentModule must no longer import EnrollmentModule.
