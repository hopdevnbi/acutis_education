ENROLLMENT PROGRESS API
-----------------------
GET /api/v1/enrollments/:enrollmentId/practice/progress

Permission: practice.read

Optional query:
curriculumId
canonicalLessonKey
from
to

Return factual metrics only.

Recommended shape:

{
  enrollmentId,
  filters,
  standard: {
    sessionsCompleted,
    inProgressSessions,
    abandonedSessions,
    questionsAttempted,
    firstAttemptCorrect,
    finalCorrect,
    firstAttemptAccuracy,
    finalAccuracy
  },
  review: {
    sessionsCompleted,
    questionsAttempted,
    finalCorrect,
    finalAccuracy,
    uniqueQuestionVersionsReviewed
  },
  lastPracticedAt
}

No masteryScore.
No raw selected answers.
No correctOptionIds.
No explanations.

METRIC SEMANTICS
----------------
sessionsCompleted:
STANDARD + COMPLETED only.

review.sessionsCompleted:
REVIEW_WRONG + COMPLETED only.

questionsAttempted:
distinct session questions in COMPLETED STANDARD sessions with >=1 attempt.
Retries do NOT increment question count.

firstAttemptCorrect:
attemptNumber=1 and isCorrect=true, per completed STANDARD session question.

firstAttemptAccuracy:
firstAttemptCorrect / completed STANDARD question count.

finalCorrect:
final/latest terminal outcome correct in COMPLETED STANDARD sessions.

finalAccuracy:
finalCorrect / total questions in COMPLETED STANDARD sessions.

If denominator 0:
follow existing API convention; if none exists, return 0 and document.

IN-PROGRESS / ABANDONED
-----------------------
Do not include in official accuracy denominators.

Expose counts separately if useful:
inProgressSessions
abandonedSessions

REVIEW METRICS
--------------
Keep separate from STANDARD.

review.questionsAttempted:
session-question occurrences in completed REVIEW_WRONG sessions.

review.finalCorrect:
final correct in completed REVIEW_WRONG sessions.

review.finalAccuracy:
finalCorrect / review questions attempted.

uniqueQuestionVersionsReviewed:
COUNT DISTINCT questionVersionId across completed REVIEW_WRONG sessions.

Chained reviews may repeat a version; distinct metric must not double-count.

LAST PRACTICED
--------------
Prefer MAX(practice_answer_attempts.submittedAt).
Nullable if no attempts.
