8. practice_sessions Table
--------------------------
Columns:

id uniqueidentifier PK
enrollment_id uniqueidentifier NOT NULL
session_type varchar(32) NOT NULL
source_session_id uniqueidentifier NULL
status varchar(32) NOT NULL
locale varchar(32) NOT NULL
curriculum_id uniqueidentifier NULL
canonical_lesson_key uniqueidentifier NULL
requested_question_count int NOT NULL
max_attempts_per_question int NOT NULL
randomize_questions bit NOT NULL
randomize_options bit NOT NULL
client_request_id uniqueidentifier NULL
created_by_user_id uniqueidentifier NOT NULL
started_at datetime2 NOT NULL
completed_at datetime2 NULL
abandoned_at datetime2 NULL
created_at datetime2 NOT NULL
updated_at datetime2 NOT NULL

9. Session Constraints
----------------------
CHECK:
requested_question_count >= 1
max_attempts_per_question >= 1

Recommended max DB guard:
requested_question_count <= 50
max_attempts_per_question <= 10

Application may use constants later, but DB should prevent absurd data.

10. Session Type/Source Constraint
---------------------------------
Enforce:

STANDARD -> source_session_id IS NULL

REVIEW_WRONG -> source_session_id IS NOT NULL

Use CHECK.

11. Status Timestamp Consistency
--------------------------------
Enforce sensible lifecycle consistency:

IN_PROGRESS:
completed_at IS NULL
abandoned_at IS NULL

COMPLETED:
completed_at IS NOT NULL
abandoned_at IS NULL

ABANDONED:
abandoned_at IS NOT NULL
completed_at IS NULL

started_at always NOT NULL.
