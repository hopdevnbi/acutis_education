10. Upload Pipeline
-------------------
Flow:

1. authenticate
2. permission
3. validate multipart exists
4. enforce global/category size limit
5. sanitize original filename
6. inspect real file signature/magic bytes
7. determine MIME
8. ensure MIME allowed for intended category
9. generate assetId
10. generate storageKey
11. compute SHA-256
12. create PENDING metadata
13. write through selected write provider
14. mark READY
15. on provider failure mark FAILED
16. return safe MediaAssetSnapshot

No provider fallback per request.
