14. Provider Registry
---------------------
CRITICAL:
Because each asset records provider, Media layer needs access to BOTH providers at runtime if configured/available.

Do NOT only instantiate the globally selected provider if that would prevent reading old LOCAL assets after switching default to S3.

Design:
- LocalStorageProvider can be available when local root configured
- S3StorageProvider available when S3 config valid
- SelectedWriteProvider determines NEW uploads
- ProviderRegistry resolves provider by stored `storage_provider`

This preserves local/S3 coexistence.

15. Write Provider Selection
----------------------------
Config:
MEDIA_STORAGE_PROVIDER=local|s3|auto

Default unset:
local

Production:
auto invalid.

local:
selected write provider LOCAL

s3:
selected write provider S3; S3 config required

auto:
non-prod only:
if S3 complete + readiness success -> S3
otherwise LOCAL

16. Dev Fallback
----------------
Support:
MEDIA_STORAGE_ALLOW_LOCAL_FALLBACK=true

Only environment != production.

If requested `s3` cannot initialize/probe:
- if fallback true -> select LOCAL for NEW writes, warning
- if false -> fail bootstrap

No per-request fallback.

17. Production Fallback
-----------------------
NODE_ENV=production:
- `auto` rejected
- local explicit allowed but log/document single-node warning
- s3 failures must not fallback local
- `MEDIA_STORAGE_ALLOW_LOCAL_FALLBACK=true` should be rejected or ignored with hard warning; prefer configuration validation failure
