HISTORY SEMANTICS
-----------------
History uses SESSION ROSTER membership, not current enrollment status.

Historical sessions remain visible after enrollment later becomes:
- TRANSFERRED
- WITHDRAWN
- COMPLETED

Once access is authorized, do not filter old attendance away because enrollment is no longer ACTIVE.

SESSION ELIGIBILITY
-------------------
For MVP attendance history:
- COMPLETED => included
- CANCELLED => excluded
- SCHEDULED => excluded

Do not treat future scheduled sessions as absences.

SUMMARY FORMULA
---------------
Canonical formula:

Eligible sessions:
status COMPLETED
AND enrollment exists in class_session_roster

totalSessions = eligible count
presentCount = PRESENT
lateCount = LATE
absentCount = ABSENT
excusedCount = EXCUSED
unmarkedCount = no attendance row

attendanceRatePercent =
round(100 * (presentCount + lateCount) / totalSessions)
if totalSessions > 0
else 0

Rules:
- LATE counts as present
- EXCUSED does not count as present
- UNMARKED lowers rate
- CANCELLED excluded
- SCHEDULED excluded

No variant formulas per actor.

ZERO / UNMARKED CONTRACT
------------------------
Counts and rate use numeric 0, never null.

Choose one history status contract:
A. nullable attendanceStatus
or
B. derived response-only "UNMARKED"

Do NOT alter persistence enum.

Whichever is chosen:
- document it
- apply consistently
- test it
