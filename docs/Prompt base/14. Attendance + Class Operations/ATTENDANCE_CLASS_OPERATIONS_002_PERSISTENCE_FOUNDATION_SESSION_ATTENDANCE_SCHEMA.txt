PART D — CLASS SESSION ENTITY / TABLE
-------------------------------------
Create migration + entity for `class_sessions`.

Columns:
- id uniqueidentifier PK, app-generated UUID
- class_id uniqueidentifier NOT NULL, FK → classes.id, ON DELETE NO ACTION
- parish_id uniqueidentifier NOT NULL, FK → parishes.id, ON DELETE NO ACTION
- academic_year_id uniqueidentifier NOT NULL, FK → academic_years.id, ON DELETE NO ACTION
- title nvarchar(128) NULL
- starts_at datetime2 NOT NULL UTC
- ends_at datetime2 NOT NULL UTC
- status varchar(32) NOT NULL
- cancelled_at datetime2 NULL
- completed_at datetime2 NULL
- created_by_user_id uniqueidentifier NOT NULL, FK → users.id, ON DELETE NO ACTION
- updated_by_user_id uniqueidentifier NULL, FK → users.id, ON DELETE NO ACTION
- created_at / updated_at project-standard UTC datetime2

Allowed status:
SCHEDULED
COMPLETED
CANCELLED

Checks:
- ends_at > starts_at
- valid status
- CANCELLED => cancelled_at NOT NULL
- non-CANCELLED => cancelled_at NULL
- COMPLETED => completed_at NOT NULL
- non-COMPLETED => completed_at NULL

Indexes:
- (class_id, starts_at)
- (parish_id, starts_at)
- status
- add (class_id, status, starts_at) only if it replaces rather than duplicates another index

No hard delete.
