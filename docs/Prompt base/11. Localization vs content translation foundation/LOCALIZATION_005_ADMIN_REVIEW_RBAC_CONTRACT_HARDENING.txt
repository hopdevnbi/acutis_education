RESOURCE LIST
-------------

translationStatus

Return metadata only, not full source payload.

RESOURCE DETAIL
---------------
Return:
binding metadata
effective translation status by target locale
latest revision summary
job summary
current source hash metadata where safe

REQUEST TRANSLATION
-------------------
POST resource translation with targetLocale.

Behavior:
- scope check
- current source resolved by adapter
- target != source
- queue idempotently
- APPROVED current => 200 short-circuit
- MACHINE_TRANSLATED current => 200 existing
- active job => 200 existing
- new queue => 201

Never call provider inline.

BULK TRANSLATION
----------------
Parish-scoped, bounded resource count, one target locale per request preferred.
No unbounded translate-all operation.
Return queued/existing/skipped counts.

RESOURCE DISCOVERY / SYNC
-------------------------
Learner GET intentionally does not create translation resources.

Add explicit admin sync/discovery:
resourceType + resourceId -> adapter fetch -> get/create binding.

Bulk discovery must use source public services only.
No source repo/entity imports.

REVISION DETAIL
---------------
Admin-only.
Return payload, source hash, target locale, status, provider/glossary metadata, audit metadata, derived stale status.

HUMAN REVIEW
------------
Human edit creates NEW immutable revision with status REVIEWED.
Do not mutate machine revision payload.

Validate using resource adapter:
IDs/structure/correctness/media semantics preserved.

APPROVAL
--------
Allowed for MACHINE_TRANSLATED or REVIEWED.
Before approval:
- resolve current source snapshot
- source hash must match
- payload adapter validation must pass

If stale:
409/422 conflict.

Approval records actor/timestamp.
No auto-approve.

APPROVED SUPERSESSION
---------------------
Latest current-hash APPROVED revision wins for NEW learner delivery.
Old APPROVED revisions remain.
Existing Practice sessions pinned to older approved revision remain unchanged.

JOB RETRY
---------
FAILED retryable jobs may be requeued.
DEAD SOURCE_CHANGED must not process obsolete source hash.
Queue fresh job from current source instead or return explicit conflict.
