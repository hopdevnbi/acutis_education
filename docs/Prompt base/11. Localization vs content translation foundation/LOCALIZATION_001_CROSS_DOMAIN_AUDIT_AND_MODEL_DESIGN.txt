CORE PRINCIPLES
---------------
- Business modules own original/source content.
- Localization owns translation metadata/workflow/resolution.
- Localization must NOT become a god module.
- Country != language != locale.
- Use BCP47 locale values.
- Do not translate on every GET.
- Human-approved translation overrides machine translation.
- Translation must be tied to source version/hash.
- Stale translations must be detectable.
- Google/provider credentials backend only.
- Do not send PII/private chat/pastoral data to translation provider by default.
- Backend localizes domain content; FE/Mobile own UI/static strings.
