Status Model
------------
Audit and finalize persisted vs derived status.

Preferred persisted:
QUEUED
TRANSLATING
MACHINE_TRANSLATED
REVIEWED
APPROVED
FAILED

Derived read status:
MISSING
SOURCE
STALE
APPROVED
MACHINE_TRANSLATED

Important:
do NOT mutate historical APPROVED revision to STALE merely because source hash changed.
Staleness should preferably be derived from:
revision.sourceContentHash != current source hash.

Document any deviation.

Approval integrity:
APPROVED requires approved_by_user_id + approved_at.
Non-approved generally null approval metadata.

------------
